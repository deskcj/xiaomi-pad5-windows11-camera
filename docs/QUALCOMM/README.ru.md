## Установка и диагностика

1. Отключите Secure Boot и включите Windows **Test Mode** по [инструкции](https://github.com/erdilS/Port-Windows-11-Xiaomi-Pad-5/blob/main/guide/Russian/disable-secureboot-ru.md).
2. Закройте приложения с камерой и запустите **`Qualcomm-ISP-Drivers-Setup.exe`**. На рабочем столе появятся папка **Qualcomm ISP Drivers** и ярлык.
3. Дождитесь сканирования устройств, нажмите **Install / Установить** и подтвердите запрос администратора Windows. Ярлык запускается обычным способом; приложение само запросит права при необходимости.
4. При сообщении **Restart required / Нужна перезагрузка** нажмите **Restart system / Перезагрузить систему**. После перезапуска войдите в Windows и немного подождите (обычно 15–30 секунд): **программа откроется сама и продолжит установку**. Если снова нужна перезагрузка, повторите этот шаг. Сохраняйте папку на рабочем столе до завершения установки.
5. Дождитесь **Installation complete / Установка завершена / 100%**, затем откройте вкладку **Cameras / Камеры** и выберите **Rear / Front**, чтобы посмотреть живое изображение обеих камер по очереди.

**Диагностика:** кнопка **Save report / Сохранить отчёт** в приложении. Логи и кадры находятся в `Рабочий стол\Qualcomm ISP Drivers\Data\Logs`. Если программа не открылась автоматически, запустите тот же ярлык на рабочем столе и нажмите «Установить».
