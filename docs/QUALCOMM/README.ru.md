## Установка и диагностика

1. Отключите Secure Boot и включите Windows **Test Mode** по [инструкции](https://github.com/erdilS/Port-Windows-11-Xiaomi-Pad-5/blob/main/guide/Russian/disable-secureboot-ru.md). Программа проверяет эти условия: драйверы пока имеют тестовую подпись.
2. Закройте приложения, использующие камеру, и запустите скачанный **`Qualcomm-ISP-Drivers-Setup.exe`**. Он установит программу в папку **Qualcomm ISP Drivers** на рабочем столе и создаст рядом ярлык. Программу можно открывать обычным запуском ярлыка.
3. Дождитесь автоматического сканирования устройств и нажмите **Install / Установить**. Подтвердите запрос прав администратора Windows. Дальше программа сама устанавливает драйверы Qualcomm ISP 253, исправляет известные проблемы установки, удаляет ненужные конфликтующие пакеты камер и проверяет кадры с обеих камер.
4. Если появится **Restart required / Нужна перезагрузка**, нажмите **Restart system / Перезагрузить систему**. После перезапуска войдите в Windows и немного подождите: **программа запустится автоматически и продолжит установку и проверку**. Обычно запуск занимает 15–30 секунд после входа. Если потребуется ещё одна перезагрузка, снова нажмите эту кнопку. Не удаляйте папку программы до завершения установки. Если окно не открылось автоматически, запустите тот же ярлык на рабочем столе.
5. Дождитесь **Installation complete / Установка завершена** и **100%**. На вкладке **Cameras / Камеры** выберите **Rear / Front**, чтобы посмотреть живое изображение задней и фронтальной камер по очереди.

Если установка остановилась с ошибкой, нажмите **Save report / Сохранить отчёт** и отправьте отчёт [разработчику](https://t.me/deskcj). Логи программы сохраняются в папке `Qualcomm ISP Drivers\Data\Logs` на рабочем столе.
