## 安装与诊断

1. 按照[此指南（英文）](https://github.com/erdilS/Port-Windows-11-Xiaomi-Pad-5/blob/main/guide/English/disable-secureboot-en.md)关闭 Secure Boot，并启用 Windows **测试模式（Test Mode）**。
2. 关闭所有使用相机预览或录像的应用，并完整解压 ZIP。
3. **以管理员身份运行 `Setup.cmd`**。Qualcomm ISP 还提供简短的 `Install.cmd` 启动入口。
4. 如果安装程序要求重启，请正常重启 Windows，并在打开任何相机应用之前再次运行同一个安装文件。等待出现 **SUCCESS 且退出代码为 0**，然后在 Windows「相机」应用中测试前后摄像头。
5. 如需排查问题，先关闭相机应用，再**以管理员身份运行 `Diagnose.cmd`**。分享 `C:\ProgramData\XiaomiPad5Camera\Logs` 中最新的完整文件夹；分享前请检查诊断图像。

`Check.cmd` 只检查压缩包完整性和平台；安装与诊断还会检查实际相机画面。

## 各路线当前状态

### Qualcomm ISP — 参考版本 253 · [路线介绍](QUALCOMM/README.zh-CN.md)

- ✅ 前后摄像头都使用硬件 IFE/IPE，并能预览和拍照。
- ✅ 已测试全分辨率照片：后置 4160 × 3120，前置 3264 × 2448。
- ✅ 已记录的测试确认了后置自动对焦、自动亮度/白平衡调节以及后置拍照闪光灯。
- ✅ 早期受控测试中，Video1080p 达到约 30 个不重复帧/秒；这不保证低照度下的预览帧率。
- 🔄 混合光照、对焦过渡、启动/切换，以及反馈的后置相机启动咔嗒声仍需改进。尚未确认达到 Android 画质，也未验证所有 Windows 系统镜像和应用。

### GPU ISP — 040 + rear065/front066 + virtual034 · [路线介绍](GPUISP/README.zh-CN.md)

- ✅ 两个传感器都向 D3D12 计算处理流程提供 RAW 数据，并通过标准虚拟相机接口输出画面。
- ✅ 较早的一次干净的 20 秒测试测得约 28–29 个不重复帧/秒，没有重复帧。
- ✅ 保留 GPU040 的色彩/镜头阴影校正（LSC）/gamma 参数表和 rear065 对焦逻辑；front066 修复了已记录的 RAW 传输异常样本。
- ❌ 尚未确认达到 Android 画质，也未验证所有应用中的可靠点按对焦、后置闪光灯和 HDR。
- 🔄 该路线需要两个后台工作进程和一个 GPU 服务；色彩、曝光、后置光学对焦和长时间运行仍需改进。

### CPU ISP — CPUISP4 · [路线介绍](CPUISP/README.zh-CN.md)

- ✅ 前后摄像头分别使用真实的 OV8856/OV13B10 帧；Windows「相机」中的预览、拍照、录像及切换均曾正常工作。
- ✅ CPU 相机路线曾在 Chrome 和 Telegram 中使用；其他应用需分别测试。
- ✅ CPUISP4 保留了 C/H 源码和 EWDK 构建命令；`Setup.cmd`/`Diagnose.cmd` 最近也再次检查了两颗摄像头的输出。
- ❌ 画质仍明显低于 Android：色彩噪声、偏软的画面、曝光和细节都需要改进。
- 🔄 尚未确认持续稳定的真实 30 帧/秒、Android 水平的对焦/闪光灯/HDR，以及与所有应用兼容。
