## 工作原理

物理驱动从真实传感器采集 Bayer RAW。两个 `GpuCameraPump` 工作进程使用 **D3D12 计算着色器**处理图像，包括色彩/白平衡、镜头阴影校正、色调/gamma、降噪和锐化。处理后的帧按顺序发布到前后 AVStream 虚拟相机，供普通 Windows 相机应用使用。`CodexNabuGpuIsp` 负责运行这些工作进程，并在空闲时释放 GPU 帧资源。

这是由 GPU 执行的软件图像处理。Qualcomm ISP 则使用硬件 IFE/IPE 流程。将计算转移到 GPU，并不能自动复现 CamX/Chromatix 的行为。

## 优势与取舍

GPU 处理降低了对较重的 CPU 图像处理路线的依赖，并提供保留源码快照、可编辑的计算着色器流程。它需要一个服务、两个工作进程及空闲内存；AE/AWB、色调与对焦仍需独立改进。启动时至少保留 **900 MiB 可用内存**。前置摄像头在硬件上是固定对焦。

## 安装与诊断

按照[指南（英文）](https://github.com/erdilS/Port-Windows-11-Xiaomi-Pad-5/blob/main/guide/English/disable-secureboot-en.md)关闭 Secure Boot 并启用 **测试模式（Test Mode）**。关闭所有相机应用，完整解压 ZIP，然后**以管理员身份运行 `Setup.cmd`**。若要求重启，正常重启后再次运行；等待 SUCCESS / 退出代码 0，再在 Windows「相机」中测试两颗摄像头。

若需重新检查实际画面，关闭相机应用，**以管理员身份运行 `Diagnose.cmd`**。分享 `C:\ProgramData\XiaomiPad5Camera\Logs` 中最新的完整文件夹，包括 `result.json` 和 `setup.log`；分享前请先查看保存的诊断帧。`Check.cmd` 只检查文件和平台。
