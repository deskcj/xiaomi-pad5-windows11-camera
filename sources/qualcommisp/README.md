# Qualcomm ISP development sources

These are this project's retained development/patch scripts and the shared installer
and camera probe source. They cover the SYS080 / DeviceMFT075b / tuning253 reference.
The Qualcomm sensor/ISP/DeviceMFT stack and firmware are supplied as compiled payloads
in the driver archive: this project does not have their original proprietary source code.
Historical development scripts are source/reference material, not a second installer.
To install the tested release, use Setup.cmd from the driver ZIP.

общего установщика и проверки кадров. Заводская часть Qualcomm и прошивка закрыты;
