# CPU ISP sources — version availability

**The downloadable driver is the original, verified CPUISP3 signed binary package.**
Its exact C/C++ source snapshot was not retained during the original development.
CPUISP4-reference is the surviving later CPU ISP source tree. It is supplied for research
and continued development, and does not claim to reproduce CPUISP3 byte for byte.
The CPUISP3 installer, INF files and public certificates are available in the driver ZIP.
The shared installer and probe source are under ../common.

Русский: скачиваемый драйвер — проверенный подписанный CPUISP3. Точные исходники
CPUISP3 были утрачены; CPUISP4-reference — сохранившаяся более поздняя версия для
исследования и продолжения работы. Она не является точным исходником CPUISP3.
Установщик CPUISP3 и INF находятся в ZIP, общий установщик и проба — в ../common.
