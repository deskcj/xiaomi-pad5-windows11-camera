# Xiaomi Pad 5 (nabu) — Windows 11 Camera Project 🚀

Welcome! This project demonstrates that the camera on the Xiaomi Pad 5 (nabu) can work under Windows 11 UEFI / Windows on ARM (WoA). This is a **Proof of Concept (PoC)**, and drivers are in active development.

## 📊 Current Status & Technical Progress

Significant progress has been made in bringing the rear camera to life on Windows 11.

### 🔧 What has been achieved
* **Hardware Validation:** Tests confirmed the rear camera sensor, four CSI lines, and RAW data path are functional.
* **Memory Allocation Fix:** The roadblock causing system crashes has been resolved by aligning the driver's memory allocation with the working front camera method.

### ⚠️ Next Steps
The core camera driver now features valid digital signatures and recognized sensors. Current focus is on configuring the 4-line CSI lane settings for a stable live video stream.
