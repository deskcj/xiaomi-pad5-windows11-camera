# О проекте

Цель проекта — реализовать нативную поддержку передней и задней камер **Xiaomi Pad 5 (nabu)** под управлением **Windows 11 ARM**.

Работа включает обратную разработку камеры Qualcomm, создание собственных драйверов AVStream, отладку низкоуровневого управления памятью и интеграцию камер в штатную мультимедийную систему Windows.

Проект находится в активной разработке.

> **Драйверы камеры пока не доступны для публичного скачивания.**

## 🚧 Над чем ведётся работа

Сейчас основное внимание уделяется интеграции задней камеры в конвейер Windows AVStream.

Сенсор задней камеры уже корректно взаимодействует с Qualcomm Spectra 380 ISP и успешно передаёт RAW-данные изображения.

Оставшиеся задачи:

- преобразование RAW-изображения;
- интеграция с AVStream;
- стабильная передача кадров;
- оптимизация драйвера;
- предварительный просмотр задней камеры в реальном времени.
